# The Odin Project Library

A simple library application built with vanilla HTML, CSS, and JavaScript. This project demonstrates a lightweight book management interface with a modal form for adding new books to the library.

## Features

- Add new books with title, author, page count, and read status
- Modal form dialog for streamlined book entry
- Clean, responsive layout using basic CSS
- Simple JavaScript object model for representing books

## Project Structure

- `index.html` — main application markup and UI structure
- `styles.css` — styling for page layout, typography, and form elements
- `javascript.js` — application logic for creating and storing books

## Getting Started

### Prerequisites

No build tools or dependencies are required. This project runs in any modern web browser.

### Running the project

1. Clone or download the repository.
2. Open `index.html` in your browser.

## Usage

- Click the **New Book** button to open the book entry dialog.
- Enter the book title, author, pages, and read status.
- Submit the form to add the book to the library display.

## Notes

This project is a lightweight frontend exercise designed for learning DOM manipulation and basic user interaction handling.
